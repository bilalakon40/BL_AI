# 🐍 Python - مقدمة سريعة

## ما هو Python؟
لغة برمجة سهلة وقوية، تُستخدم في:
- بناء تطبيقات AI (مثل مشروعك!)
- تطوير مواقع (Instagram, YouTube)
- تحليل بيانات
- أتمتة مهام

## كيف تشغّل Python؟
افتح **PowerShell** واكتب:
```bash
python
```
ستظهر لك شاشة `>>>`. اكتب فيها:
```python
print("مرحباً يا بلال!")
```

للخروج اكتب:
```python
exit()
```

## كيف تنشئ ملف Python؟
1. افتح **VS Code** من قائمة Start
2. **File** → **New File** (أو `Ctrl+N`)
3. احفظه باسم `hello.py` في مجلد `D:\bilal AI\BL_AI\learn\01_basics\`
4. اكتب الكود
5. للحفظ: `Ctrl+S`
6. للتشغيل: افتح Terminal في VS Code (`Ctrl+` `) واكتب: `python hello.py`

## ملاحظة مهمة
كل سطر يبدأ بـ `#` هو **تعليق** - لا يُنفذ، فقط لتوضيح الكود.
